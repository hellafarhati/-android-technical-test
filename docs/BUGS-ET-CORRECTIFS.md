# Bugs et correctifs

- `GlobalScope.launch` dans le ViewModel → `viewModelScope`
- `MutableSharedFlow` sans `replay`, écran vide après rotation → `StateFlow` + `stateIn(WhileSubscribed)`
- Singleton d'analytics qui garde un `Context` d'`Activity` (fuite mémoire) → supprimé
- `DetailsActivity` déclarée `LAUNCHER`, deux icônes dans le lanceur → une seule activité + Navigation Compose
- Détail ouvert sans l'identifiant de la photo → argument `photoId` type-safe
- Logs HTTP activés en release au lieu de debug (condition inversée) → corrigé via `NetworkConfig`
- Aucune persistance locale → Room comme source de vérité
- Test unitaire fourni qui ne compilait pas → suite de tests réécrite
- `catch (_: Exception) {}` qui masque les erreurs → `RefreshResult` avec états Loading/Error/Empty
- Aucune injection de dépendances → Hilt
- DTO réseau utilisé directement dans l'UI → un modèle par couche
- Chargement déclenché depuis l'UI (`LaunchedEffect`) → déclenché par le ViewModel
- `modifier` du parent réappliqué à l'image enfant → chaque composant a son propre `Modifier`
- `collectAsStateWithLifecycle(emptyList())` sur un `SharedFlow` → `StateFlow` typé
- Pas de thème sombre → ajout de `values-night`
- `compileSdk` incompatible avec les versions de librairies utilisées → mis à jour
- Bloc `dependencies` mal placé dans `build.gradle.kts` → corrigé
- `consumerProguardFiles` pointant vers un fichier inexistant → supprimé
- Imports et dépendances de test inutilisés → nettoyés
- Images potentiellement injoignables → placeholder et image de repli
